Data Flow · Request Lifecycle
↓ Inventory Management Request
1
User Interaction (Vue 3 UI)
User selects filters (warehouse, category, status, time period) via FilterBar composable.
useFilters() → reactive state update
2
API Request (Axios)
Frontend calls backend with query params via api.js helpers.
GET /api/orders?warehouse=SF&status=Delivered
3
FastAPI Route Handler
Route parses query params, applies filter logic via apply_filters() + filter_by_month().
@app.get("/api/orders") → apply_filters(data)
4
In-Memory Data Lookup
Filtered against mock_data loaded at startup. Pydantic validates each record.
mock_data["orders"] → List[Order] (Pydantic)
5
JSON Response → Reactive UI
Frontend computed properties re-render views with filtered data.
response.data → Vue reactive → DOM update
🤖 Claude API / Notebook Flow
1
Notebook Cell Execution
User runs a Jupyter cell with an Anthropic SDK call, passing messages and optional tools.
client = anthropic.Anthropic(api_key=...)
2
Claude API Request
SDK sends messages to Claude. Tools defined as JSON schemas enable agentic loops.
client.messages.create(model, messages, tools)
3
Tool Use / Agentic Loop
If stop_reason == "tool_use", execute tool locally and feed results back to Claude.
while response.stop_reason == "tool_use": ...
4
Eval Harness (Day 2 Session 1)
Structured grader evaluates model outputs against test cases. Metrics computed.
grade(expected, actual) → pass/fail + score
5
Output + Metrics Display
Results rendered in notebook: TTFT, cost, OTPS, accuracy, pass/fail rates.
display(results_df) # pandas / rich output
